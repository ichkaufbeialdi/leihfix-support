# LeihFix – Support

**LeihFix** ist eine iPhone-App zur Verwaltung verliehener Gegenstände und Geldbeträge.

## Hilfe & Support

LeihFix benötigt **kein Benutzerkonto und keine Anmeldung**. Deine LeihFix-Einträge und zugehörigen Fotos werden lokal auf deinem iPhone gespeichert.

Bei technischen Fragen, Fehlern oder sonstigen Anliegen kannst du hier eine Support-Anfrage erstellen:

**[Support-Anfrage für LeihFix erstellen](https://github.com/ichkaufbeialdi/leihfix-support/issues/new)**

## Häufige Fragen

### Wie lege ich einen neuen Eintrag an?
Tippe in LeihFix auf das Plus-Symbol. Erfasse einen Gegenstand oder Geldbetrag, die betreffende Person und optional ein Rückgabedatum, eine Notiz und ein Foto.

### Kann ich ein Foto hinzufügen?
Ja. Du kannst direkt mit der Kamera fotografieren oder ein vorhandenes Bild aus deiner Fotomediathek auswählen. Der Zugriff erfolgt erst nach deiner iOS-Freigabe.

### Wie funktionieren Erinnerungen?
Wenn du ein Rückgabedatum festlegst, kann LeihFix auf Wunsch eine lokale Benachrichtigung auf deinem iPhone planen.

### Wo werden meine Daten gespeichert?
Deine LeihFix-Einträge und Fotos werden lokal auf deinem Gerät gespeichert. LeihFix verwendet derzeit keinen eigenen Cloud-Speicher für diese Daten, keine Werbung und kein appübergreifendes Tracking.

### Wie stelle ich einen Kauf wieder her?
Öffne **Mehr → LeihFix Plus → Käufe wiederherstellen**.

### Wie verwalte ich mein Jahresabo?
Ein aktives Jahresabo kannst du über die Apple-Aboverwaltung deiner Apple-ID verwalten oder kündigen.
